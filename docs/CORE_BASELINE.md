# Lang Systems Core Baseline

- Adopted 9 November 2026 from [Lang Systems Core Development at 9bd812d](https://github.com/langzonedev/LangSystems-Core-Development/tree/9bd812d352fd061f14c20a719f0f147c62430a10).
- Project and human playtest owner is langzonedev. Review at the first material scope or architecture change.
- A static web-first arcade game uses Canvas, native input events and Web Audio. Rendering, UI and scoring are separate modules. The repo and game client are public. Data is limited to a device-local score and sound setting.
- Product and UX guidance shaped the single hold, aim and release loop, readable feedback and reduced-motion mode. Architecture, delivery, security and QA guidance were applied by the implementation agent. Independent human gameplay approval is pending.
- Direct publication from `main` is authorised for this candidate. A browser smoke test and human gameplay pass are separate verification steps.
